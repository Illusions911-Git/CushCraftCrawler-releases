# CushCraft Crawler

A cartoon roguelite dungeon crawler that is also a TV game show: walk room to room before your steps run out,
fill your backpack, let the fights play out, hunt hidden bosses, and find the hidden stairs. 1 to 4 players (online co-op).

## Download and play (Windows)

1. Open [the latest release](https://github.com/Illusions911-Git/CushCraftCrawler-releases/releases/latest).
2. Download **CushCraftCrawler-win64.zip** and unzip it anywhere.
3. Double-click **CushCraftCrawler.exe**. (Windows may warn about an unknown app: "More info", then "Run anyway".)

## Updates

The game checks this page on the title screen. When a new version is out, click **Update** and it downloads
the new version and restarts. In co-op, if the host has a newer version, the game offers the update when you
join: let it restart, then join again.
